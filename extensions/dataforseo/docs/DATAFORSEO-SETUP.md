# DataForSEO Account Setup

Step-by-step guide to getting DataForSEO API credentials for the Claude SEO extension.

## 1. Create Account

1. Go to [app.dataforseo.com/register](https://app.dataforseo.com/register)
2. Sign up with your email address
3. Verify your email

New accounts include $1 in free trial credit, and the minimum top-up is $50 (fetched
2026-09-25 from [dataforseo.com/seo-mcp-server](https://dataforseo.com/seo-mcp-server)
and [dataforseo.com/pricing](https://dataforseo.com/pricing)).

## 2. Find API Credentials

1. Log in to [app.dataforseo.com](https://app.dataforseo.com)
2. Go to **API Access** in the left sidebar
3. Your credentials are:
   - **API login**: shown on the API Access page (usually your registered email)
   - **API password**: generated by DataForSEO and different from your account
     password ([docs](https://docs.dataforseo.com/v3/auth/))

These are the values you'll enter when running the extension installer.

## 3. Understanding Credits

DataForSEO uses a credit-based system:

- Each API call is billed from a prepaid balance
- Different endpoints have different costs
- Monitor usage at [app.dataforseo.com/dashboard](https://app.dataforseo.com/dashboard)

**Live-mode prices** (DataForSEO pricing pages, fetched 2026-09-25; re-check before quoting):

| Endpoint | Price |
|--------------|-----------------|
| Google Organic SERP | $0.002 per SERP of 10 results |
| Google Ads search volume | $0.09 per task (up to 1,000 keywords) |
| DataForSEO Labs (most endpoints) | $0.012 per task + $0.00012 per item |
| Backlinks (summary, list, anchors...) | $0.024 per request + $0.000036 per row |
| OnPage Instant Pages | $0.00015 per page (basic) |
| Lighthouse | $0.005 per page |
| ChatGPT LLM Scraper | $0.004 per results page |
| LLM Mentions | $0.1 per request + $0.001 per row |

Per-endpoint source links: `extensions/dataforseo/README.md` (section API Credits).

## 4. Manual MCP Configuration

If the installer's auto-configuration fails, add this to `~/.claude/settings.json`:

```json
{
  "mcpServers": {
    "dataforseo": {
      "command": "npx",
      "args": ["-y", "dataforseo-mcp-server@3"],
      "env": {
        "DATAFORSEO_LOGIN": "your-api-login",
        "DATAFORSEO_PASSWORD": "your-api-password",
        "FIELD_CONFIG_PATH": "/home/youruser/.claude/skills/seo/dataforseo-field-config.json"
      }
    }
  }
}
```

Replace the login, password, and FIELD_CONFIG_PATH with your actual values.

- `@3` pins the major version. v3 exposes `api_request`, `docs_search`, `docs_index` and
  `docs_list_sections` instead of the v2 per-endpoint tools; the skills support both.
- v3 needs Node.js 22+. It reads `DATAFORSEO_LOGIN` (`DATAFORSEO_USERNAME` still works as
  an alias). `ENABLED_MODULES` from v2 configs is ignored and can be deleted.
- Source: [dataforseo-mcp-server README](https://github.com/dataforseo/mcp-server-typescript#readme).

## 5. Verify Installation

After installing, start Claude Code and run:

```
/seo dataforseo serp test query
```

If you see search results, the extension is working correctly.
